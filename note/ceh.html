CEH 道德駭客筆記

從攻擊者的角度理解系統弱點， 再從防禦者的角度思考如何偵測、修補與降低風險。

認證學習 閱讀時間約 8 分鐘 持續更新

01. CEH 是什麼？

CEH 全名為 Certified Ethical Hacker， 是 EC-Council 推出的道德駭客認證。 學習內容涵蓋資訊安全觀念、資訊蒐集、網路掃描、 弱點分析、系統與網頁攻擊，以及相關防禦措施。

核心觀念

道德駭客不是未經授權地入侵系統， 而是在明確授權與測試範圍內， 找出安全弱點並提出改善建議。

學習時可以建立的三種能力

  • 理解攻擊：知道攻擊者可能如何尋找入口與利用弱點。
  • 判讀證據：能解讀掃描結果、封包、系統紀錄與告警。
  • 提出防禦：將發現的問題轉化為修補、監控與風險降低措施。

02. 道德駭客流程

可以先用以下流程建立整體概念。 實際測試步驟會依系統類型、授權範圍及測試規範調整。

01
Reconnaissance｜資訊蒐集

蒐集目標的公開資訊、網域、IP 與網路架構線索。

02
Scanning｜掃描

確認主機、連接埠、服務與可能暴露的資訊。

03
Enumeration｜列舉

在授權範圍內進一步確認服務、帳號或網路資源資訊。

04
Vulnerability Analysis｜弱點分析

確認可能的漏洞、設定錯誤與風險等級。

05
Reporting｜報告與改善

整理證據、評估影響、提出修補建議並追蹤改善結果。

容易混淆的地方

資訊蒐集是取得目標相關線索； 掃描是識別主機、連接埠或服務； 列舉則是針對已發現的服務進一步取得詳細資訊。

03. 資訊蒐集與網路掃描

資訊蒐集（Reconnaissance）

常見的學習主題包括：

  • WHOIS：查詢網域註冊相關資訊。
  • DNS 查詢：理解網域名稱與 IP 位址的對應關係。
  • OSINT：利用公開來源蒐集資訊。
  • Traceroute：觀察封包到目的地可能經過的路徑。

網路掃描（Scanning）

掃描的目的在於了解目標目前對外呈現的網路服務狀態。

項目 用途 需要注意
Host Discovery 確認主機是否可被探測 防火牆可能影響探測結果
Port Scanning 了解連接埠狀態 開放連接埠不等於存在漏洞
Service Detection 識別服務與版本線索 版本資訊可能不完整或不準確
OS Detection 推測作業系統類型 通常是推測結果，不一定完全正確

04. 弱點分析（Vulnerability Analysis）

弱點分析是將掃描結果、版本資訊、設定狀態與其他證據交叉比對， 判斷系統是否可能存在安全問題。

弱點管理的基本流程

  1. 確認資產與測試範圍。
  2. 執行經授權的弱點掃描。
  3. 檢視弱點描述、受影響版本與嚴重程度。
  4. 確認誤判，並評估弱點在實際環境中的影響。
  5. 安排修補或補償性控制措施。
  6. 重新掃描或驗證，確認改善結果。

CVSS 與弱點嚴重程度

CVSS（Common Vulnerability Scoring System） 是用來描述弱點嚴重程度的評分框架。 評分可以協助排定處理優先順序，但不應單獨取代實際風險評估。

實務筆記

弱點分數高，不一定代表在每個環境中都最急迫。 還要考慮資產重要性、是否暴露於外部、是否有可利用條件， 以及現有防護措施。

05. 常見攻擊類型

網路與系統安全

  • Sniffing：擷取並分析網路流量。
  • Spoofing：偽冒來源或身分資訊。
  • Man-in-the-Middle：攻擊者介入通訊雙方之間。
  • DoS / DDoS：透過大量或特殊流量影響服務可用性。
  • Password Attacks：針對密碼強度、重複使用或驗證流程進行攻擊。

網頁與應用程式安全

  • SQL Injection：不安全的資料庫查詢處理可能導致非預期操作。
  • Cross-Site Scripting（XSS）：應用程式未妥善處理輸入或輸出時，可能造成惡意腳本執行。
  • Broken Access Control：權限檢查不足，導致使用者存取不應取得的資源。
  • Session Hijacking：工作階段識別資訊遭竊取或濫用。

人員與惡意程式威脅

  • Social Engineering：利用信任、情緒或認知偏誤誘使他人採取不安全行為。
  • Phishing：透過偽冒訊息或網站誘騙使用者。
  • Malware：包含木馬、病毒、蠕蟲及勒索軟體等。
記憶方法

複習每種攻擊時，試著回答四個問題： 攻擊目標是什麼？利用什麼弱點？ 會造成什麼影響？可以如何偵測與防禦？

06. 常見工具整理

以下是學習資安時常見的工具與用途。 實際功能會因版本、設定及使用情境而異。

工具 主要用途 學習方向
Nmap 主機探索、連接埠與服務掃描 理解掃描結果及偵測限制
Nessus 弱點掃描與風險資訊整理 判讀弱點、確認誤判及追蹤修補
Wireshark 網路封包擷取與分析 TCP/IP、DNS、HTTP 等協定
Burp Suite 網頁應用程式安全測試 HTTP、工作階段及輸入驗證
Metasploit 授權環境中的安全測試框架 理解漏洞驗證與測試流程
SIEM 集中收集、關聯分析與監控事件 告警判讀、事件調查及應變

請只在自有設備、合法靶場或明確授權的環境中進行測試。 不要對未經授權的主機執行掃描或攻擊。

07. 防禦與應對

CEH 不只需要理解攻擊方式，也要能說明相應的防禦措施。 可以將攻擊技術與日常維運工作連結起來。

風險 可能的防禦措施
不必要的開放連接埠 關閉非必要服務、限制防火牆規則
已知軟體弱點 修補更新、版本管理、弱點複掃
帳號遭盜用 多因素驗證、最小權限、登入監控
網路流量異常 網路分區、流量監控、IDS / IPS
釣魚與社交工程 郵件過濾、使用者教育、事件通報流程
可疑端點活動 端點防護、集中紀錄、告警調查與隔離
